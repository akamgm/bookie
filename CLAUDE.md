# Building a Quiver app

Run `quiver docs intro` for the lay of the land — what Quiver is,
the data model, how apps should behave, sparks, and the verification
loop. Bare `quiver docs` lists every topic; `quiver docs <topic>`
prints a specific one.

The initial repository is already valid and uses
`Bookie` as its working display name. Replace the
starter summary and preview copy with language specific to the user's request
as you begin building — `quiver check` rejects a push that still carries the
template's generic summary, and a display name of "New App".
